GUIAS, EXERCÍCIOS E CONSULTA

Documentação da Kinein Vectis

Instale a Vectis, escolha sua linguagem e construa um programa pequeno. Os guias mostram os passos; os exercícios ajudam a entender o código. Use o manual quando precisar consultar um recurso ou atalho.

02 / APRENDER

Continue um projeto em C++.

Crie ola-kinein e siga no mesmo projeto: da primeira mensagem ao cálculo de temperaturas e a uma lista de leituras. Cada etapa tem um resultado para conferir e exercícios para praticar.

  1. 01→

    Prepare a IDE

    Baixe o beta para Linux e abra a Vectis pela primeira vez.

    Resultado: IDE pronta para começar
  2. 02→

    Crie seu primeiro C++

    Crie ola-kinein, compile e faça sua primeira mensagem aparecer no terminal.

    Resultado: Olá, Kinein!
  3. 03→

    Faça o programa calcular

    Continue no mesmo main.cpp: use dois valores de temperatura e calcule a média.

    Resultado: media: 22.00 C
  4. 04→

    Trabalhe com mais leituras

    Evolua o cálculo para uma lista de amostras e trate um sensor que ainda não tem dados.

    Resultado: sala: 21.75 C

Prefere outra linguagem? Os percursos de Rust e Python estão logo abaixo. Para conhecer os painéis, a busca e o Git, veja os guias de uso da IDE.

Estudos e capítulos indicam o ambiente e a versão em que foram testados.

03 / SUA LINGUAGEM

Escolha por onde começar.

Os percursos de C++, Rust e Python começam na IDE 0.3.5 e continuam na mesma linguagem. O exercício de C começa pelo terminal. Todos têm código completo, saída esperada e pequenas mudanças para você testar.

EXERCÍCIO NO TERMINAL

C

Guarde dois números, calcule a média e confira a saída de um programa C11. Você só precisa do compilador e de um terminal.

Começar em C →PROJETO NA IDE · CMAKE

C++

Crie ola-kinein e avance no mesmo main.cpp: mensagem, média de temperaturas e várias leituras.

Começar em C++ →PROJETO NA IDE · CARGO

Rust

Prepare o Rust, crie ola-rust e execute pelo Cargo. Depois transforme a mensagem em um cálculo de temperaturas.

Começar em Rust →PROJETO NA IDE · .VENV

Python

Crie ola-python com ambiente virtual e testes. Continue no mesmo main.py para calcular e exibir uma média.

Começar em Python →
