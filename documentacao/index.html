LEIA NO SEU RITMO

Documentação da Kinein Vectis

Comece pela versão pública e pelo manual. O Guia da IDE virá antes dos projetos guiados, com cada tarefa testada na versão indicada.

● Versão pública indicada: 0.2.0 beta para Linux x86_64. Confira a release antes de instalar.

A 0.3.0 está em desenvolvimento. Veja o andamento das etapas; os recursos dessa versão ainda não fazem parte do download público.

02 / APRENDER

Primeiro a IDE, depois os projetos.

O manual técnico já está disponível no repositório da IDE. Os estudos de linguagem podem começar sem depender de recursos específicos da Vectis. Os guias de uso da IDE seguirão esta ordem:

  1. Guia da IDE

    Instalação, interface, primeiro projeto, build, execução, testes, depuração e solução de problemas na versão citada.

  2. Projetos guiados

    Exemplos locais e pequenos que introduzem C++, C, Python e Rust junto com as tarefas feitas na Vectis.

ESTUDO DE LINGUAGEM · C++20

Processe telemetria local

Um primeiro programa de software para IoT: amostras simuladas, média por sensor e tratamento de ausência de dados.

Os estudos de linguagem indicam o ambiente em que foram testados. Os guias da IDE incluirão a versão usada, os passos, o resultado esperado e a solução de problemas após a reprodução do fluxo descrito.
