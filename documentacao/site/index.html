PROJETO ABERTO À COLABORAÇÃO

O site também é um projeto.

Aqui estão as peças que existem hoje e os próximos trabalhos que podemos verificar. Este roteiro trata do site; o estado da IDE está descrito na página inicial.

01 / PUBLICADO

O que existe hoje.

Página inicial, índice de documentação e primeiro estudo de C++20. O site tem três temas de leitura, três cores de destaque e passa por verificações de código, HTML e links internos antes da publicação.

O estudo de telemetria é independente da IDE. Os guias de tarefas na Vectis ainda dependem de reprodução dos passos na versão pública indicada.

02 / COMO FUNCIONA

Páginas estáticas e conteúdo verificado.

Astro gera o site, e o GitHub Pages entrega os arquivos. O código não usa servidor ou banco de dados. As preferências de tema ficam no navegador. Estudos de linguagem são escritos em Markdown e só geram página pública quando estão marcados como verificados.

Para trabalhar no repositório, use Node.js 24, npm ci enpm run dev. Antes de propor uma mudança, executenpm run build:pages. A documentação de arquitetura no repositório descreve coleções, rotas e publicação em detalhes.

03 / ROADMAP DO SITE

Próximos trabalhos, com critério de conclusão.

  1. Revisar leitura e navegação

    Conferir telas estreitas, contraste dos temas, foco por teclado e movimento reduzido. Corrigir cada defeito reproduzido.

  2. Ampliar os estudos verificados

    Validar entradas e testes em C++ com exemplos executados. Melhorar a navegação entre estudos quando houver mais páginas.

  3. Publicar o Guia básico da IDE

    Criar a rota própria e testar instalação, interface e primeiro projeto na versão pública citada antes de publicar.

  4. Manter a base técnica

    Reduzir avisos de coesão de CSS e conferir os links externos essenciais durante revisões de conteúdo.

Recursos ainda não validados da IDE não têm data de publicação como guia. O roadmap detalhado registra as condições de cada entrega.

04 / CONTRIBUIR

Correções e estudos são bem-vindos.

Explique o problema, mostre o resultado esperado e indique como verificou a mudança. Para um estudo, registre fontes, ferramentas e resultado da execução. A publicação fica com os mantenedores.
