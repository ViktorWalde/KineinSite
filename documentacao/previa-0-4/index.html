0.4 · EM DESENVOLVIMENTO

A próxima Vectis, por dentro.

A 0.4 reúne a nova interface, inspirada nas IDEs JetBrains, e o trabalho com embarcados. Aqui você pode acompanhar um projeto C++ na interface que está sendo preparada para o lançamento.

A versão pública para experimentar hoje continua sendo o beta 0.3.5 para Linux ↗.

0.4
Prévia em desenvolvimento

Você está vendo uma versão em construção. A interface e os recursos ainda podem mudar até o lançamento.

O que acontece no vídeo

Um programa pequeno calcula a média de 21 e 23 °C. O projeto tem CMake e um repositório Git local. A sequência vai do código ao resultado, com uma passagem pelas ferramentas detectadas e pelo histórico do projeto.

  1. 0–6 s: o arquivo src/main.cpp está aberto no editor, junto à árvore do projeto.
  2. 6–12 s: a compilação termina e o painel Build informa sucesso.
  3. 12–18 s: o terminal integrado abre no diretório do projeto.
  4. 18–24 s: a execução imprime media: 22.00 C, o resultado esperado.
  5. 24–30 s: o painel Ferramentas exibe as ferramentas detectadas, suas versões e itens ausentes.
  6. 30–36 s: o painel Git mostra o primeiro commit do exemplo.
  7. 36–42 s: a interface volta ao terminal.

O que isso permite testar

O ciclo básico — abrir, ler o código, compilar, executar e conferir a saída — já pode ser experimentado no beta. Os tutoriais de início mostram esse fluxo com as telas e os limites da 0.3.5. O vídeo mostra esse trabalho na interface em construção.

O que está vindo com a 0.4

Uma reformulação do frontend, com o editor no centro, e uma base mais consistente para trabalhar com embarcados. Os dispositivos, SDKs e fluxos de gravação e depuração do lançamento serão anunciados após implementação e testes. O vídeo acompanha C++ no computador; a demonstração com dispositivos virá quando essas integrações estiverem prontas.

Sobre esta gravação

Executável de desenvolvimento da 0.4, capturado no Linux x86_64 em 8 de outubro de 2026. O vídeo tem 42 segundos e mostra a aplicação em execução.

Comece com seu próprio projeto

Siga o tutorial para compilar e executar seu primeiro C++. Você vai criar o projeto, compilar e conferir a saída na IDE. Se encontrar uma dificuldade, o capítulo de diagnóstico ajuda a separar código, compilador e ambiente.
