Kinein Vectis 0.3.5

Abra projetos remotos por SSH, organize arquivos pela árvore e consulte Markdown ao lado do código. O beta 0.3.5 também reúne melhorias no terminal e no painel Grafana.

Ler a nota completaBaixar a 0.3.5 ↗
  • Escolha projetos remotos por SSH

    Use aliases do ~/.ssh/config ou preencha o perfil a partir de uma linha ssh. Navegue pelas pastas do computador remoto e abra um espelho local com rsync. A conexão exige autenticação por chave.

  • Organize os arquivos do projeto

    Abra a pasta atual com o comando kinein. Navegue pela árvore com teclado, selecione vários arquivos, copie, recorte e cole ou arraste para o gerenciador de arquivos. As transferências aparecem em Jobs.

  • Arquivo externo no editor

    Soltar um arquivo de fora do projeto abre uma aba somente leitura: nada é importado e a origem não é escrita.

  • Leia Markdown ao lado do código

    Abra a prévia Markdown lado a lado e encontre declarações pela busca de símbolos do projeto. As abas mantêm a identidade do arquivo durante a navegação.
