# Wallpaper

`wallpaper-site.png` é o original da imagem de abertura. O site entrega uma versão WebP otimizada. A presença deste arquivo no repositório não concede licença de reutilização por terceiros.

`wave-flow.svg` é uma máscara vetorial de curvas com bordas difusas, usada pelo CSS para formar as ondas do fundo da página. As cores vêm dos tokens de tema; a máscara não faz parte da imagem de abertura.
