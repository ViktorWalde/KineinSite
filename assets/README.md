# Imagens do site

O ícone e o wallpaper desta pasta são os originais usados pela interface. O Astro gera versões otimizadas para as páginas. A presença destes arquivos no repositório não concede licença de reutilização por terceiros.

`textures/noise.png` é gerado por `scripts/generate-noise.mjs` (ruído com semente fixa). Ele é aplicado sobre degradês escuros para quebrar as faixas de cor e pode ser regenerado a qualquer momento.

`ide/` guarda capturas reais da IDE geradas por `scripts/capturar-ide.sh` a partir do AppImage publicado; a versão e a data de cada conjunto ficam em `src/data/ide-screens.ts`.
