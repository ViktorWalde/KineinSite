APRENDER · GUIA DA IDE

Seu primeiro projeto começa aqui.

Siga o percurso de C++ para construir e melhorar um único programa. Se preferir Rust ou Python, há um tutorial próprio para cada linguagem. Os passos da IDE usam o beta 0.3.5.

UM PROJETO EM QUATRO ETAPAS

Do primeiro “olá” às temperaturas.

Instale a IDE, crie ola-kinein e avance no mesmo arquivo C++. Cada etapa termina com um resultado que você consegue conferir.

  1. 01→

    Prepare a IDE

    Baixe o beta para Linux e abra a Vectis pela primeira vez.

    Resultado: IDE pronta para começar
  2. 02→

    Crie seu primeiro C++

    Crie ola-kinein, compile e faça sua primeira mensagem aparecer no terminal.

    Resultado: Olá, Kinein!
  3. 03→

    Faça o programa calcular

    Continue no mesmo main.cpp: use dois valores de temperatura e calcule a média.

    Resultado: media: 22.00 C
  4. 04→

    Trabalhe com mais leituras

    Evolua o cálculo para uma lista de amostras e trate um sensor que ainda não tem dados.

    Resultado: sala: 21.75 C

Para usar a IDE no dia a dia

  1. Instalar e abrir a Kinein VectisBaixe a versão pública, confira se o arquivo chegou íntegro, instale o atalho e o comando kinein e abra a IDE pela primeira vez.10 min · 0.3.5
  2. Conhecer a telaUm passeio pela janela com o projeto aberto: o cabeçalho, o trilho, o editor, o painel de baixo e o que a barra de status conta.10 min · 0.3.5
  3. Busca e atalhosAbra arquivos pelo nome, procure texto no projeto e no arquivo aberto, ache comandos e os atalhos de cada um.10 min · 0.3.5
  4. GitTransforme o projeto num repositório, faça o primeiro commit pela janela do Git, veja o que mudou e consulte o histórico.15 min · 0.3.5
  5. Quando algo dá erradoLeia um erro de compilação pela aba Problemas, vá direto à linha, corrija e saiba onde a IDE registra o que fez para relatar um problema.10 min · 0.3.5
